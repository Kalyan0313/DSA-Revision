# Check if Array Is Palindrome

## Problem Description

Given an array or string `nums`, check whether it reads the same **forwards and backwards**.  
Return **true** if it is a palindrome, otherwise return **false**.

---

## Problem Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9` (for integer arrays)
- `nums` may also be a string consisting of printable characters.

---

## Input Format

The first argument is an array or string `nums`.

---

## Output Format

Return **true** if `nums` is a palindrome, otherwise return **false**.

---

## Example Input

**Input 1:**  
nums = [1, 2, 3, 2, 1]

**Input 2:**  
nums = [1, 2, 3, 4]

---

## Example Output

**Output 1:**  
true

**Output 2:**  
false

---

## Example Explanation

**Explanation 1:**  
The array `[1, 2, 3, 2, 1]` reads the same forwards and backwards.

**Explanation 2:**  
The array `[1, 2, 3, 4]` does not read the same forwards and backwards.
